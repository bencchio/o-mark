# Page format

This document declares its own sheet in the front matter above: A5 in landscape.
It keeps that sheet whatever `page_format` and `page_orientation` say in
`config.toml`.

`Ctrl+R` flips the orientation for this session only. Close and reopen the file,
and it is A5 landscape again. Export it with `Ctrl+P` and the PDF comes out on the
same sheet, with the margins the config sets.

A separator line starts a new page, and every page has the size of the sheet.
